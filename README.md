# Road Safety Analysis

This repository contains an exploratory analytical work involving road-safety data and Python-based modelling.

The notebooks cover several approaches to examining road-safety patterns, including clustering, count regression, and sliding-window analysis.

## Repository Contents

| Directory | Contents |
|---|---|
| `Clustering/` | Feature preparation and clustering notebooks |
| `Negative_Binomial/` | Negative-binomial and Poisson-related modelling notebooks |
| `Sliding_Window/` | Sliding-window analysis notebook |
| `Data/` | Data files used in the analyses |

The Python environment configuration files are also included.
